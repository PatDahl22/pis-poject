# Security Documentation

Den här mappen innehåller dokumentation för säkerhetsarkitekturen i IoT Fall-Larm.

## Innehåll

- `threat-model.md` – hotbild och attackyta
- `security-requirements.md` – säkerhetskrav
- `mqtt-security.md` – säker kommunikation mellan edge och fog
- `data-protection.md` – skydd av lokal lagring och databas
- `secrets-management.md` – hantering av hemligheter
- `fog-hardening.md` – hardening av Raspberry Pi / fog hub
- `security-architecture.md` – övergripande säkerhetsarkitektur
- `security-demo.md` – demo / proof of concept
- `security-review.md` – gap analysis och nästa steg
