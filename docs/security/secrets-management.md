# Secrets Management

## Hemligheter i systemet
- WiFi-lösenord
- API-nycklar
- eventuella tokens eller credentials

## Risker
- hårdkodade hemligheter i repo
- lagring i klartext
- delning mellan teammedlemmar utan kontroll

## Målbild
- inga hårdkodade hemligheter
- säker config-strategi
- möjlighet till rotation av nycklar
